# Відповіді на питання для самоперевірки

1. Яка різниця між DDL і DML?
   - DDL (Data Definition Language) — CREATE, ALTER, DROP — працює зі структурою (таблиці, індекси)
   - DML (Data Manipulation Language) — INSERT, UPDATE, DELETE — працює з даними (рядки)

2. Чому INSERT потрібно писати з явним переліком колонок?
   - Щоб код не ламався після ALTER TABLE
   - Щоб не залежати від порядку колонок
   - Щоб не передавати значення для GENERATED ALWAYS AS IDENTITY

3. Для чого потрібен RETURNING?
   - Повертає значення з щойно доданого/зміненого рядка
   - Зручно для отримання згенерованого id

4. Що робить ON CONFLICT DO NOTHING?
   - Пропускає вставку при порушенні унікальності
   - Корисний для upsert (update or insert)

5. Чому score = NULL не працює?
   - NULL означає "невідоме значення", не можна порівнювати через =
   - Правильно: score IS NULL або score IS NOT NULL

6. Що станеться, якщо виконати UPDATE або DELETE без WHERE?
   - Зміниться/видалиться всі рядки
   - Уникнути: спочатку SELECT з тією ж умовою, потім транзакція

7. Чим TRUNCATE відрізняється від DELETE?
   - TRUNCATE — швидше, видаляє все, скидає лічильник id
   - DELETE — повільніше, з WHERE, не скидає лічильник

8. Чому видалення курсу може завершитись помилкою?
   - Зовнішній ключ забороняє видалення, якщо є залежні рядки
   - Способи: каскадне видалення, видалення залежних, м'яке видалення

9. Що таке транзакція?
   - Об'єднує кілька команд в одну неподільну операцію
   - COMMIT — зберегти, ROLLBACK — скасувати

10. Чому в нумерації id бувають пропуски?
    - Послідовність видає номер до перевірки обмежень
    - При ROLLBACK номер не повертається

11. Що таке індекс?
    - Додаткова структура даних для прискорення пошуку
    - Прискорює читання, сповільнює запис, займає місце

12. Для яких колонок PostgreSQL не створює індекс автоматично?
    - Для зовнішніх ключів (крім тих, що в складених ключах)

13. Чим відрізняються Seq Scan та Index Scan?
    - Seq Scan — послідовне сканування всіх рядків
    - Index Scan — швидкий пошук через індекс

14. Чому не можна підставляти значення в SQL через f-string?
    - SQL-ін'єкції — небезпечно
    - Правильно: параметри %s

15. Що таке проблема N+1 запитів?
    - Один запит на кожен елемент у циклі
    - Вирішення: один запит з JOIN
