### Тестування часу "серцебиття"

Моніторингова система клієнта надсилає сигнал що вона працездатна кожні 30 сек. або менше.

Засобами автоматизації проаналізуйте наданий нам лог: [heartbeat\hblog](https://github.com/alex-pancho/testing_ideas/blob/main/heartbeat/hblog)

Змініть заготовку - файл hb_proces.py так щоб був аналіз правильності вимог:
    для кожного випадку де heartbeat більше 31 сек але менше рівно 33 логувало WARNING в файл hb_test.log
    для кожного випадку де heartbeat більше 33 логувало ERROR в файл hb_test.log

Необов'язкова частина, виклик для найвитриваліших:

(на оцінку не впливає, на самооцінку - впливає)

Врахуйте, що моніторингових процесів декілька і вони ідентифікуються по ключу наприклад:

    KEY TSTFEED0300
    KEY TSTFEED0240

це два різні процеси, відповідно, для пошуку наступного "удару" слід також враховувати ключ.
